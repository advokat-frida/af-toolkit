# assets

Brand masters, and the licence texts that get copied into `public/licenses/` at staging time.

| Path | What it is |
|---|---|
| `frida-fox-forest.png` | The fox mark. The served copy lives at `public/assets/` |
| `licenses/af-fonts.txt` | SIL Open Font License 1.1, for Anton, Archivo and Space Grotesk |
| `licenses/lucide-static.txt` | ISC, for the Lucide icons |

The mark and the wordmark are **not** covered by the repository's MIT licence. Fork the code, use
your own identity: [`../TRADEMARKS.md`](../TRADEMARKS.md) explains where the line is and why it is
drawn there.
